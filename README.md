# Варіант 21: Магазин мобільної гри — геми та монети

Навчальний проєкт на Scala 3. Стан гравця змінюється подіями, без `var`:
кожна подія повертає новий `State` (через `.copy`) або помилку `Left(String)`.

## Події

- `BuyGems(gems, realMoney)` — купівля гемів за реальні гроші;
- `ConvertGemsToCoins(gems)` — обмін гемів на монети (1 гем = 10 монет);
- `UpgradeCard(cardName, costCoins)` — покращення карти за монети;
- `DailyGift(coins, gems)` — щоденний подарунок.

## Основні функції (`GemShop`)

- `apply(state, event)` — застосувати одну подію;
- `replay(events)` — програти список подій через `foldLeft`;
- `top3Upgrades(state)` — три найдорожчі покращення.

Конвертація неможлива без достатньої кількості гемів, покращення — без достатньої кількості монет.
`totalGemsSpent` рахує геми, витрачені на конвертацію.

## Запуск тестів
